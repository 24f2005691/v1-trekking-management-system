# Trekking Management System

A role-based web application built using Flask that allows administrators, staff, and trekkers to efficiently manage treks, bookings, and participant records.

## Technologies Used

- Flask
- SQLite
- SQLAlchemy
- HTML
- CSS
- Bootstrap
- JavaScript
- Jinja2

## Installation

1. Clone the repository.

```bash
git clone <repository-url>
cd Trekking-Management-System
```

2. Install the required packages.

```bash
pip install -r requirements.txt
```

3. Run the application.

```bash
python app.py
```

4. Open your browser and visit:

```
http://127.0.0.1:5000
```
